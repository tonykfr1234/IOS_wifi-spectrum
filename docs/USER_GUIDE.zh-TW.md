# 使用指南

## iOS 版能做與不能做的事

| 能做 | 不能做（Apple 未開放） |
| --- | --- |
| 目前連線的 SSID、BSSID、廠商、加密類型 | 附近的 Wi-Fi 清單 |
| IP、子網路、IPv6、網路狀態 | 頻道、頻寬、訊號強度（RSSI） |
| 測速、區域網路裝置探索 | Wi-Fi 7 MLO 連結 |
| TCP 延遲、DNS、連接埠掃描 | ICMP Ping |
| 頻道計算機、子網路計算機 | |

需要附近網路、頻道與頻寬分析，請使用 Android 版。

## 第一次開啟

1. 「連線」分頁會請你允許位置權限。iOS 規定要有這個權限才能讀取 Wi-Fi 名稱與 BSSID，App 不會讀取座標。
2. 「區網」第一次掃描時，iOS 會詢問「本地網路」，請允許，否則找不到任何裝置。
3. 不小心拒絕了：到 iPhone「設定 → 隱私權與安全性 → 定位服務／本地網路」找到「Wi-Fi 頻譜分析儀」打開。

## 五個分頁

### 連線

- SSID、BSSID 與廠商。BSSID 若是隨機位址，會顯示「隨機／本地管理位址」。
- 加密類型：開放與 WEP 以紅色標示。
- 網路介面：IPv4、子網路遮罩、網段、IPv6、是否為低數據模式或計量網路。
- 下拉可重新整理。

### 測速

- 按「開始測速」：先測延遲，再測下載、上傳，各 3 次取中位數。
- 測一次約用 100 MB 流量，用行動網路時請留意。
- 下方保留最近 20 次結果（關閉 App 後清除）。

### 區網

- 按「開始掃描」：同時用 Bonjour 找會自我介紹的裝置，並對同網段每個位址測試 80、443、22、445、554、62078 連接埠。
- /24 網段約 1 分鐘內完成；超過 1,024 個位址的網段只做 Bonjour 探索。
- iOS 不提供其他裝置的 MAC 位址，所以區網清單沒有廠商名稱。

### 工具

| 工具 | 用途 |
| --- | --- |
| 頻道計算機 | 選頻段、主頻道、頻寬，算出佔用範圍、中心頻道、涵蓋頻道、PSC／DFS 與 UNII 子頻段。規則與 Android 版相同 |
| 子網路計算機 | 輸入 `192.168.1.10/24` 或 `192.168.1.10 255.255.255.0`，算出網路位址、廣播位址、可用主機範圍 |
| TCP 延遲 | 量 10 次連線建立時間，顯示最短／中位／最長、抖動與遺失率 |
| DNS 查詢 | 用系統 DNS 查 A、AAAA 與正式名稱 |
| 連接埠掃描 | 留空掃描常用 19 個；也可輸入 `80,443` 或 `8000-8010`（一次最多 1,024 個） |

### 關於

- 「示範模式」：顯示模擬的台北公寓資料，沒有 Wi-Fi 時也能看完整介面。
- 隱私說明與資料來源。

## 常見狀況

| 狀況 | 原因與處理 |
| --- | --- |
| 連線分頁顯示「沒有連上 Wi-Fi」 | 手機沒連 Wi-Fi，或在模擬器上執行（模擬器沒有 Wi-Fi 資訊） |
| 看不到 SSID | 沒有允許位置權限 |
| 區網找不到裝置 | 沒有允許本地網路權限，或路由器開啟了「AP 隔離」 |
| 測速失敗 | 網路中斷或防火牆擋住 speed.cloudflare.com |
| TCP 延遲全部逾時 | 主機不存在、該連接埠沒開，或被防火牆擋下；換成 443 再試 |
